# 🇨🇳 ZhongWen Duo (中文 Duo)
> **เว็บแอปพลิเคชันเรียนภาษาจีนสำหรับสองพี่น้อง สู่ระดับเจ้าของภาษา (Native-Like Chinese Learning WebApp)**

สร้างขึ้นเป็นพิเศษเพื่อให้ลูกสาวทั้งสองคนฝึกภาษาจีนอย่างสนุกสนาน ครอบคลุม 4 ทักษะ (ฟัง พูด อ่าน เขียน) พร้อมระบบโปรไฟล์คู่พี่น้อง แอนิเมชันลำดับขีดอักษรจีน กราฟระดับเสียงวรรณยุกต์ และเพื่อน AI ติวเตอร์

---

## 🌟 ฟังก์ชันหลักที่มีในระบบ

1. **✍️ ระบบฝึกเขียนอักษรจีนทีละขีด (Hanzi Stroke Order)**
   - แสดงแอนิเมชันลำดับขีดทีละเส้นด้วย `hanzi-writer` (โหมดปกติ / โหมดสโลว์โมชัน)
   - กระดานฝึกเขียนจริงด้วยนิ้วมือหรือ Stylus/Apple Pencil
   - ตรวจจับความแม่นยำ (Accuracy Scoring) พร้อมเสียงเอฟเฟกต์พู่กันจีนและดาวกระจาย (Confetti)
   - แตกรากศัพท์ (Radicals) และเทคนิคจำตัวอักษรแบบนิทาน (Mnemonics)

2. **🃏 การจำคำศัพท์อัจฉริยะ (Spaced Repetition System - SRS)**
   - แฟลชการ์ด 3D พลิกดูคำแปล คำอ่านไทย และตัวอย่างประโยค
   - ปุ่มเปิด/ปิดพินอิน (Pinyin Toggle) สำหรับท้าทายให้อ่านตัวจีนล้วน
   - ระบบประเมินตนเองตามรอบการทบทวนเพื่อการจดจำระยะยาว

3. **🎙️ โค้ชสอนวรรณยุกต์และตรวจจับการออกเสียง (Tone & Pitch Coach)**
   - กราฟจำลองระดับเสียง 5 ระดับ (5-Pitch Scale) สำหรับเสียง 1, 2, 3, 4
   - บันทึกเสียงพูดผ่านไมโครโฟนมือถือเพื่อตรวจสอบความถูกต้อง
   - มินิเกมทดสอบหู (Tone Ear Training Quiz) ฝึกฟังแยกเสียงวรรณยุกต์

4. **🐼 คุยกับ AI ติวเตอร์เป่าเปา (Interactive AI Tutor)**
   - สนทนาภาษาจีนแบบ Real-time ผ่าน Google Gemini AI
   - พูดคุยผ่านไมโครโฟนหรือพิมพ์ข้อความ
   - มีปุ่มฟังเสียงอ่านสำเนียงจีนแท้ๆ พร้อมพินอินและคำแปลไทย
   - หากยังไม่ได้ใส่ API Key มีระบบ Fallback โต้ตอบอัจฉริยะในตัว

5. **🐾 สัตว์เลี้ยงวิเศษสองพี่น้อง (Virtual Pet Evolution)**
   - สัตว์เลี้ยงจะค่อยๆ วิวัฒนาการจาก ไข่วิเศษ 🥚 ➔ วัยทารก 🐣 ➔ นักรบจิ๋ว 🥋 ➔ ผู้พิทักษ์สูงสุด 🐉
   - ให้อาหารและลูบหัวสัตว์เลี้ยงเมื่อทบทวนคำศัพท์
   - ภารกิจรวมพลังสองพี่น้อง (Sibling Co-op Quest) รวมพลังสะสม 300 ดาว

6. **👨‍👧‍👧 แดชบอร์ดติดตามพัฒนาการสำหรับคุณพ่อ (Parent Dashboard)**
   - ดูสถิติเปรียบเทียบพัฒนาการของลูกสาวทั้ง 2 คน
   - นับจำนวนวันเรียนต่อเนื่อง (Daily Streak)
   - ระบบตั้งเวลาแจ้งเตือนทบทวนศัพท์ประจำวัน (Smart Habit Reminder)

## 🚀 วิธีเปิดใช้งานบนเครื่องตัวเอง (Local Development)

```bash
# 1. ติดตั้ง Dependencies (ทำเสร็จแล้ว)
npm install

# 2. คัดลอกไฟล์ Environment Variables (ไม่บังคับ - มี fallback ในตัว)
cp .env.example .env.local

# 3. รัน Development Server
npm run dev
```

เปิดเบราว์เซอร์ไปที่: `http://localhost:3000`

## ☁️ วิธี Deploy ขึ้น Vercel (ขั้นตอนง่ายๆ)

1. **ผ่าน Vercel CLI**:
   ```bash
   npx vercel
   ```
2. **ผ่าน GitHub**:
   - Push โฟลเดอร์โปรเจกต์นี้ขึ้น GitHub Repository ส่วนตัว
   - เข้า [vercel.com](https://vercel.com) กด **"Add New Project"** แล้วเลือก Repo นี้
   - ในหน้าการตั้งค่า **Environment Variables** ให้ใส่ (ถ้ามี):
     - `GEMINI_API_KEY`: API Key จาก Google AI Studio
   - กด **Deploy** เว็บแอปจะออนไลน์พร้อมใช้งานบนมือถือทันที!
